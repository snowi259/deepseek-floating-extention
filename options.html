生成参数

回答被截断时调大它（例如 4096）。

等待首个字或两次数据之间的最长时间，超时会自动中断并提示。

越低越稳定，越高越发散。解题场景建议 0.2 ~ 0.7。

思考模式

部分模型会先输出「思考过程」。本插件不会把思考过程当成最终答案显示， 只会把它折叠在答案下方。

选择「关闭」时，插件会按下面的参数形式发送关闭指令。如果服务端拒绝该参数， 插件会自动去掉参数重试，并在悬浮窗里明确提示「无法确认思考模式是否已关闭」—— 不会假装已经关闭。

不同服务商字段不同，没有通用写法。enable_thinking 只会在你明确选择时发送， 不会作为所有模型的通用参数。

外观

使用小贴士

  1. 在任意网页点击浏览器工具栏上的插件图标（或按 Alt+Shift+D），悬浮窗会出现在网页右侧。
  2. 悬浮窗里可以拖动标题栏移动、拖右下角调整大小，位置和尺寸会自动记住。
  3. 「📷 可视区」截当前屏幕，「🖼 整页」滚动拼接整个网页，「✂️ 区域」拖动选择一部分。
  4. 先点「🎯 解题」会自动填入解题提示词，你可以改完再发送。
  5. 截图识题需要支持视觉输入的模型，否则接口会返回错误——插件会把错误原文显示出来。
API 文档： DeepSeek 官方文档 · 本扩展不收集任何数据，也不经过任何中转服务器。
