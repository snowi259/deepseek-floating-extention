# DeepSeek Flash · 网页悬浮 AI

一个 Chrome / Edge 浏览器扩展（Manifest V3），在**当前网页内部**注入一个可拖动、可缩放、始终覆盖在网页内容上方的 AI 悬浮窗。可以用它截取网页、上传图片、输入问题，并直接调用**你自己配置的** DeepSeek Flash（或任何 OpenAI 兼容）API 来解题、分析图片。

- 不是独立弹窗，不是侧边栏，不是 iframe 套壳网站
- 没有后端服务器，没有中转，不收集任何数据
- API Key 只存在你自己的浏览器里

---

## 一、功能

### 悬浮窗

- 点击工具栏图标 / 按 `Alt+Shift+D` 显示或隐藏
- 出现在网页右侧，可拖动标题栏移动，拖右边缘 / 下边缘 / 右下角改变大小
- 位置和尺寸自动保存，下次打开（含换网页后）沿用
- 最小化、关闭、重新打开，快捷键切换
- 使用 Shadow DOM 完全隔离样式，不修改网页原有布局，不拦截网页的点击、滚动与输入
- 深色 / 浅色 / 跟随系统三种主题
- 极高的 z-index（2147483647），普通网页元素无法遮挡

### 对话

- 多轮对话，用户消息与 AI 回复分开显示
- Markdown 渲染（标题、列表、表格、引用、代码块、行内代码、链接、粗斜体）
- 数学公式渲染（`$$...$$`、`\[...\]`、`\(...\)`、`$...$`）
- 流式逐字输出 + 停止生成按钮
- 复制 AI 回答、清空当前对话
- 一次可附加最多 4 张图片，图片和文字可以放在同一条消息里发送
- 支持从剪贴板直接粘贴图片

### 截图

- **可视区截图**：`chrome.tabs.captureVisibleTab()`，截取当前屏幕
- **整页截图**：自动滚动 + 逐屏截图 + canvas 拼接
- **区域截图**：全屏遮罩，鼠标拖选，确认后按设备像素比与页面缩放精确裁剪
- **本地上传**：PNG / JPG / JPEG / WEBP
- 截图/图片会先显示缩略图，发送前可以随意删除
- 点击缩略图可以放大预览

### 解题

- 「🎯 解题」按钮一键填入解题提示词（识别题目 → 逐题解答 → 计算题给步骤 → 选择题给选项），发送前可自由修改

## 二、目录结构

```text
deepseek-floating-ai/
├── manifest.json        # Manifest V3 配置
├── background.js        # Service Worker：开窗、截图、代理流式请求
├── api.js               # OpenAI 兼容 Chat Completions 客户端（仅在后台运行）
├── content.js           # 悬浮窗控制器：面板、拖动缩放、对话、截图编排
├── content.css          # 悬浮窗样式（Shadow DOM 内）
├── ui.js                # Shadow DOM 外壳与模板
├── screenshot.js        # 截图：可视区 / 整页拼接 / 区域选择
├── image.js             # 图片校验、缩放、压缩
├── markdown.js          # 轻量 Markdown + LaTeX 渲染（零依赖）
├── options.html         # 设置页
├── options.css
├── options.js
└── README.md
```

> 说明：需求里提到的 `popup.html` 没有提供，因为点击工具栏图标必须**直接切换悬浮窗**；
> 一旦设置了 `default_popup`，`chrome.action.onClicked` 就不会触发，悬浮窗就无法用图标开关。
> 设置入口放在悬浮窗右上角的 ⚙ 按钮里。

## 三、安装

### Chrome

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择整个 `deepseek-floating-ai` 文件夹
5. 建议把它固定到工具栏（拼图图标 → 图钉），方便一键开关

### Edge

1. 打开 `edge://extensions/`
2. 左侧打开「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择 `deepseek-floating-ai` 文件夹

安装后会自动打开设置页。以后可以随时点击悬浮窗右上角的 ⚙，或在扩展详情页点击「扩展程序选项」再次打开。

### 关于图标

本项目没有内置图标文件，加载后会显示 Chrome 默认的拼图图标，这不影响任何功能。
如果想自定义：在扩展目录下新建 `icons/`，放入 `icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`，
然后在 `manifest.json` 里补上：

```json
"action": {
  "default_title": "显示 / 隐藏 AI 悬浮窗（Alt+Shift+D）",
  "default_icon": { "16": "icons/icon16.png", "32": "icons/icon32.png", "48": "icons/icon48.png", "128": "icons/icon128.png" }
},
"icons": { "16": "icons/icon16.png", "32": "icons/icon32.png", "48": "icons/icon48.png", "128": "icons/icon128.png" },
```

## 四、API 配置教程

打开设置页，依次填写：

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| **API Base URL** | 完整的 Chat Completions 地址 | `https://api.deepseek.com/chat/completions` |
| **API Key** | 服务商给你的密钥 | 空 |
| **模型 ID** | 可自由填写任意模型 | `deepseek-flash` |
| **最大输出 Token** | 回答被截断时调大 | `2048` |
| **Temperature** | 0 ~ 2 | `0.7` |
| **请求超时时间** | 等待首个字 / 两次数据之间的最长秒数 | `60` |
| **流式输出** | 是否逐字显示 | 开 |

填完点「保存设置」，再点「测试连接」验证。测试会发送一条极短的消息，成功会显示模型回复，失败会显示经过脱敏的错误原文。

### 地址容错

- 只填 `https://api.deepseek.com` → 自动补成 `.../chat/completions`
- 填 `https://xxx/v1` → 自动补成 `https://xxx/v1/chat/completions`
- 自定义路径保持原样

### 服务商模板

设置页提供四个模板，套用后仍可手动改：

| 模板 | 地址 | 思考参数形式 |
| --- | --- | --- |
| DeepSeek 官方 | `https://api.deepseek.com/chat/completions` | `thinking: {type:"disabled"}` |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `enable_thinking: false` |
| OpenAI | `https://api.openai.com/v1/chat/completions` | `reasoning_effort: "minimal"` |
| Cloudflare Workers AI | `.../accounts/ACCOUNT_ID/ai/v1/chat/completions` | 不发送 |

> Cloudflare 的地址里需要把 `ACCOUNT_ID` 换成你自己的账户 ID，模型名也要换成该账户可用的模型。
> 不同服务商、不同模型支持的字段差异很大，模板只是起点，请以服务商文档为准。

### 请求格式

默认发送 OpenAI 兼容格式：

```json
{
  "model": "deepseek-flash",
  "messages": [{ "role": "user", "content": "你好" }],
  "stream": true,
  "max_tokens": 2048,
  "temperature": 0.7,
  "thinking": { "type": "disabled" }
}
```

带图片时使用多模态格式：

```json
{
  "model": "deepseek-flash",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "请识别截图中的题目并给出解答。" },
      { "type": "image_url", "image_url": { "url": "data:image/png;base64,...." } }
    ]
  }],
  "stream": true
}
```

插件**不会**把图片文件名当图片发，**不会**把图片转成文字描述，也**不会**假装完成了视觉识别——API 不支持视觉时会直接把错误显示出来。

## 五、截图功能使用教程

### 1. 可视区截图 📷

点击「📷 可视区」→ 悬浮窗自动隐藏 → 截取当前屏幕 → 悬浮窗恢复并把截图放进输入框下方的附件区。

### 2. 整页截图 🖼

点击「🖼 整页」后：

1. 自动隐藏页面上的 `position: fixed` 元素（避免固定导航栏在每一屏重复出现）
2. 临时隐藏滚动条并关闭平滑滚动
3. 逐屏滚动、逐屏截图（受浏览器频率限制，约每 0.5 秒一屏）
4. 用 canvas 拼接成一张长图
5. 恢复页面滚动位置、固定元素与滚动条

处理原则：

- 按 `document.scrollHeight` 计算总高度，最后不足一屏时按实际滚动位置对齐
- 截完自动还原，不会让你停在页面底部
- 单张图最多拼 40 屏；超过会停止并提示「只截取了前 N 屏」
- 输出画布上限约 2400 万像素、单边 26000 px，超长页面会等比缩小
- 整页图默认用 JPEG（质量 0.92）控制体积，普通截图保持 PNG

**限制**：如果页面内部用的是自己的滚动容器（`document` 本身不滚动），整页截图只能截到当前屏，插件会提示失败并建议改用可视区截图。浏览器不提供一次性截取整页的 API，这是 `captureVisibleTab` 的固有约束。

### 3. 区域截图 ✂️

点击「✂️ 区域」→ 页面出现全屏遮罩 → 按住左键拖动 → 松开后出现「✓ 截取 / 重选 / 取消」→ 点「✓ 截取」完成。

- 按 `Esc` 或点「取消」退出
- 裁剪时使用 `截图实际像素 / window.innerWidth` 作为缩放比例，因此**页面缩放（Ctrl +/-）和高 DPI 屏幕都能正确对齐**
- 选区外的页面会被压暗，便于框选

### 4. 上传本地图片 📎

支持 PNG / JPG / JPEG / WEBP，单文件上限 25 MB。也可以在输入框里直接 `Ctrl+V` 粘贴图片。

所有图片都会在本地做一次处理：宽度超过 1600 px 或总像素超过 400 万时等比缩小；体积仍过大时自动转 JPEG 并继续降质，保证不撑爆 API 请求。

### 5. 解答截图 🎯

点击「🎯 解题」会把提示词填进输入框：

> 请仔细识别图片中的所有题目，确保题目内容识别准确，然后逐题解答。按照题目要求输出答案。如果是计算题，请提供必要的计算步骤。如果是选择题，请明确给出选项和答案。如果图片中存在多个题目，请逐题回答。

你可以随意修改，然后点「发送」。**注意：解题效果取决于模型是否支持视觉输入。**

## 六、思考模式配置说明（重要）

不同服务商关闭「思考」的字段完全不同，**没有通用写法**：

| 服务商 / 模型 | 关闭思考的字段 |
| --- | --- |
| DeepSeek 官方 | `"thinking": { "type": "disabled" }` |
| Qwen / DashScope / vLLM 上的 Qwen3 | `"enable_thinking": false` |
| OpenAI 推理模型 | `"reasoning_effort": "minimal"` |
| 其他 | 可能不支持，或需要别的字段 |

所以设置页提供了两个选项：

1. **思考模式**：`关闭` / `开启` / `自动`
   - `自动` = 不发送任何思考参数，完全由服务端默认行为决定
2. **思考参数形式**：`自动` / `DeepSeek` / `enable_thinking` / `reasoning_effort` / `不发送`
   - `自动` 会按 API 域名判断（deepseek.com → `thinking`，dashscope/aliyuncs → `enable_thinking`，openai/azure → `reasoning_effort`，其他默认按 DeepSeek 写法）

### 关于「关不掉」的诚实处理

如果接口返回 400 并且错误信息与 thinking / reasoning / 未知字段有关，插件会：

1. **自动去掉该参数重试一次**
2. 在悬浮窗里显示黄色提示：*「该接口 / 模型不接受关闭思考模式的参数，已改为不发送该参数、按服务端默认行为重试。注意：无法确认思考模式是否真的被关闭。」*

也就是说：**不会假装已经关闭**。如果服务端就是要思考，插件会如实告诉你。

### 思考过程不会被当成答案

- 流式响应里的 `reasoning_content` / `reasoning` 会被单独累积
- 生成过程中只显示「模型正在思考…（已接收 N 字）」
- 生成结束后折叠成「思考过程（N 字，已折叠）」，默认收起
- 如果模型**只**返回了思考内容、没有最终答案，会明确报错：
  > 模型只输出了思考内容，没有给出最终答案。建议：关闭思考模式、调大最大输出 Token 后重试。

## 七、视觉输入说明

- 插件会按 OpenAI 多模态格式发送 `image_url`（`data:image/...;base64,...`）
- **是否支持图片取决于模型与接口**，插件无法预知
- 当接口返回 400 / 422 且错误信息里出现 image / vision / multimodal / image_url / visual 时，
  会附加提示：*「当前模型或接口可能不支持图片输入。请换用支持视觉的模型，或去掉图片后重试。」*
- 这只是一个**基于错误文本的启发式判断**，最终以服务端返回为准；原始错误信息会脱敏后一并显示
- 多轮对话中，历史图片最多保留最近 4 张；更早的图片会用文字注明「另有 N 张历史图片因长度限制未随本次请求发送」，避免请求体无限膨胀

## 八、权限与隐私

| 权限 | 为什么需要 |
| --- | --- |
| `storage` | 保存设置、悬浮窗位置尺寸 |
| `activeTab` | 点击图标时临时获得当前标签页的操作权限 |
| `scripting` | 在安装前就已打开的标签页里补注入内容脚本 |
| `<all_urls>`（host） | ① 让悬浮窗能出现在任意网页；② `captureVisibleTab` 需要；③ 后台直接请求你填写的任意 API 域名 |

隐私承诺：

- API Key 只写入 `chrome.storage.local`，**不参与任何同步**
- 所有请求都由扩展后台直接发往**你自己填写的 API 地址**，不经过任何中间服务器
- 截图、图片只在你的浏览器内存里处理，上传目标只有你配置的 API
- 源码中没有任何硬编码密钥
- 错误信息里出现密钥时会被替换成 `sk-xxxx***`
- 对话历史只保存在当前页面的内存中，刷新即消失，不落盘

唯一例外：接口域名必须由你填写。如果你填写的是别人的服务器，数据自然会发给那台服务器——这是你的选择，不是插件的中转。

## 九、已知限制与替代方案

| 限制 | 原因 | 替代方案 |
| --- | --- | --- |
| `chrome://`、`edge://`、扩展商店、`view-source:` 页面无法使用 | 浏览器禁止向这些页面注入脚本 | 换到普通网页使用 |
| PDF 阅读器（内置 viewer）无法截图 | 受保护页面 | 先下载 PDF，用「上传图片」或截图工具 |
| 带 DRM 的视频页面可能截出黑屏 | 受保护内容 | 无 |
| 整页截图对「内部滚动容器」页面无效 | 页面本身不滚动 | 用「可视区」逐段截 |
| 整页截图很长的页面会被缩小 | 浏览器 canvas 尺寸与内存限制 | 改用「区域」分段截取 |
| 数学公式是自研子集，不是完整 KaTeX | MV3 不允许远程加载脚本，项目要求零依赖 | 常见分式/根式/上下标/希腊字母/矩阵均支持；极冷门宏会以红色原文显示 |
| 后台请求超时会中断 | 避免无限等待 | 在设置里调大超时时间 |

## 十、故障排查

**点击图标没反应，图标上出现红色 `!`**
→ 当前是受保护页面（`chrome://`、扩展商店等），换一个普通网页。
→ 若扩展刚更新过，请刷新页面：旧内容脚本已失效，需要重新注入。

**提示「尚未填写 API Key」**
→ 点悬浮窗右上角 ⚙ 打开设置页填写并保存。

**HTTP 401**
→ Key 写错、被吊销或账户没余额。错误信息里不会显示完整 Key。

**HTTP 404**
→ 地址少了 `/chat/completions`，或模型 ID 不存在。先用「测试连接」验证。

**请求超时**
→ 检查网络 / 代理；或在设置里把超时时间调到 120 秒以上。

**回答被截断**
→ 调大「最大输出 Token」。悬浮窗里也会出现「回答达到上限」的提示。

**模型只输出思考、没有答案**
→ 在设置里把「思考模式」改成关闭（并选对参数形式），或换模型 / 调大 Token。

**图片发不出去 / 提示不支持视觉**
→ 换一个支持视觉的模型；或只发文字问题。

**整页截图失败**
→ 页面内部滚动、或页面高度超过限制。改用「可视区」或「区域」分段截。

**上传图片后很久没反应**
→ 大图会在本地压缩，通常 1 ~ 3 秒；控制台若报 canvas 错误，改用更小的图片。

## 十一、开发说明

- 纯原生 JavaScript / HTML / CSS，无构建步骤、无 npm 依赖、无框架
- `background.js` 是 ES Module（`"type": "module"`），`api.js` 只被它 `import`
- 内容脚本按顺序以传统脚本注入：`markdown.js → image.js → screenshot.js → ui.js → content.js`，
  它们通过 `window.DSMarkdown / DSImage / DSShot / DSUI` 共享能力
- 悬浮窗挂在 `<html>` 上而不是 `<body>`，SPA 替换 body 也不会消失；另有 3 秒一次的存活检查
- 修改代码后：在扩展管理页点「重新加载」，然后**刷新目标网页**

### 消息协议

| 方向 | 类型 | 说明 |
| --- | --- | --- |
| 后台 → 内容脚本 | `DSF_TOGGLE` | 显示 / 隐藏悬浮窗 |
| 后台 → 内容脚本 | `DSF_PING` | 检测是否已注入 |
| 内容脚本 → 后台 | `DSF_CAPTURE_VISIBLE` | 截取可视区域，返回 dataURL |
| 内容脚本 → 后台 | `DSF_OPEN_OPTIONS` | 打开设置页 |
| 设置页 → 后台 | `DSF_TEST` | 测试连接 |
| 内容脚本 → 后台（Port） | `start` / `abort` | 流式对话请求与中断 |
| 后台 → 内容脚本（Port） | `delta` / `notice` / `done` / `error` | 增量文本、提示、完成、错误 |
